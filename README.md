# 🚗 Vehicle Rental System

A full-stack **Vehicle Rental Management System** built using **Java, JSP, Servlets, JDBC, and MySQL**.

The application allows users to create an account, browse available vehicles, book vehicles, manage bookings, and view invoices. It also provides an **Admin Panel** for managing vehicles, users, and bookings.

---

## ✨ Features

### 👤 User
- User Registration
- Secure Login
- Forgot & Reset Password
- OTP Verification
- Edit Profile
- Change Password
- Browse Available Vehicles
- View Vehicle Details
- Book Vehicles
- View My Bookings
- Cancel Booking
- Generate/View Invoice
- Logout

### 👨‍💼 Admin
- Admin Login
- Admin Dashboard
- Add New Vehicles
- Edit Vehicle Details
- Delete Vehicles
- Manage Vehicles
- View Registered Users
- Manage Bookings
- Update Booking Status
